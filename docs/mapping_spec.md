# Mapping specification

Generated by `scripts/build_sdtm.py` on 2026-11-04.

Each domain is transposed from SDTM to the CRF page it came from, then mapped back. The match rate beside every variable is measured on that reconstruction against the published data — it is not a claim.

## About the source layer

The pilot study publishes mapped SDTM only; no raw or CRF-shaped data exists for it anywhere. The CRF layer here is therefore **derived from the published SDTM**, using `define.xml` origin annotations for page structure. It is a labelled fixture for exercising and proving the mapping, and is never presented as trial data.

This is why the round trip matters: it is the evidence that the mapping
specification is complete, in the sense that nothing the CRF layer holds is
lost or invented on the way back to SDTM.
